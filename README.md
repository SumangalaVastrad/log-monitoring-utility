# Log Monitoring Utility
A Python script that reads a log file, counts CRITICAL, ERROR, WARNING and INFO lines, and saves a summary report to report.txt.

## How to run
python log_monitor.py
Then type the log file name, for example sample.log.

## Features
- Counts log levels
- Saves a summary report
- Handles a missing file without crashing

## Tech
Python, file handling, string manipulation, loops, conditional logic, exception handling, Git
